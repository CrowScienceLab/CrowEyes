## 요청한 7가지

1. 경로를 ‘컴퓨터 > 드라이브 > 폴더 > 하위 폴더’ 형태로 복원했습니다. 각 항목을 눌러 이동합니다. 긴 경로는 휠로 앞뒤를 볼 수 있으며, 왼쪽 … 메뉴에서 컴퓨터와 모든 상위 폴더를 선택할 수 있습니다. 경로가 같은 동안 탐색 위젯을 재생성하지 않습니다.
2. 아이콘 격자의 Ctrl 추가·해제, Shift 범위 선택, Ctrl+Shift 추가 범위 선택을 처리합니다. 드래그 기능 등록 뒤에 수정키 이벤트를 명시적으로 연결하여 선택이 다른 바인딩에 가로채이지 않게 했습니다. Shift 범위는 현재 검색 결과에 보이는 파일 기준입니다.
3. 검색 칸 옆의 정보 탭을 제거했습니다. 사진 정보는 기존 첫 줄 정보 아이콘이나 F8로 열 수 있습니다.
4. 검색 옆에는 AI 생성 판단 / 성인 필터 / 영역 글자인식 / 정보 색인의 독립 컬러 아이콘만 배치했습니다. 마우스를 올리면 기능명이 표시됩니다. 도구 버튼은 제거했습니다.
5. ‘정보 색인’은 현재 폴더 전체 이미지의 촬영일과 전체 이미지 OCR 글자를 함께 저장합니다. 같은 글자 인식을 중복 실행하지 않습니다. 파일 크기·수정 시각이 같은 완료 항목은 다시 OCR하지 않고 건너뜁니다. 취소 시 이미 완료한 자료는 유지합니다.
   ‘파일(OCR) 찾기’에서 파일명·색인한 글자·촬영일을 통합 검색합니다. 예: 학교 / 2026-10 / 학교 2026-10. 여러 단어는 모두 포함하는 자료를 찾습니다. 날짜의 :, -, /, . 구분을 맞춰 검색합니다. 파일명은 색인 없이도 검색할 수 있습니다.
   사진 속 글자와 촬영일은 먼저 색인해야 합니다. 촬영일 메타데이터가 없는 사진과 해당 형식에서 읽지 못한 촬영일은 날짜 검색에 포함되지 않습니다. RAW/HEIC의 촬영일 읽기는 기존 지원 범위를 따릅니다.
6. 정리 메뉴의 ‘검색 색인 삭제’를 추가했습니다. 현재 폴더 / 선택한 사진 / 없는 파일 / 전체 검색 DB 중 범위를 고릅니다. 원본 사진은 삭제하지 않습니다. 삭제 후 DB 공간을 정리합니다. 작업 중에는 색인 삭제를 제한하여 저장과 삭제가 충돌하지 않게 합니다.
7. 뷰어·편집의 도구막대 높이를 동일하게 예약하고, 모드 전환 중 테마 재적용과 같은 패널의 분리·재부착을 제거했습니다. 세 번째 열이 닫힌 동일한 구조에서 전환하면 캔버스 크기, 확대율, 분할 위치가 유지됩니다. 열린 검사 열을 닫거나 편집 조절 줄을 끝내는 경우에는 실제 표시 영역 변경에 따른 배치 변경이 필요합니다.
