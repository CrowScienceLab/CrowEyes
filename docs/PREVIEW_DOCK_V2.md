# CrowEyes 2.0 · 오른쪽 도구 탭 / 컬러 아이콘 검토본

검토용 실행 파일: `D:\App coding\Crow Eyes\dist\preview-v2.0.0\CrowEyes\CrowEyes.exe`

제품 버전은 2.0.0입니다. 같은 폴더의 `_internal`이 필요합니다. 설치 프로그램, ZIP, MSIX 및 GitHub/Store 업로드는 이번 작업에 포함하지 않았습니다.

## 반영 사항

1. 파일목록의 썸네일 격자가 짧을 때 스크롤 영역을 창 높이보다 작게 만들지 않도록 보정했습니다. 위쪽으로 계속 스크롤해도 목록 시작점 앞에 빈 공간이 생기지 않습니다.
2. 오른쪽 인덱스에 **정보 / AI 생성 판단 / 성인 필터 / 도구**를 배치했습니다. 선택하면 오른쪽 세 번째 열이 열리고 같은 탭을 다시 누르면 닫힙니다. 처음에는 닫혀 있습니다. 전체 화면에서는 탭도 숨깁니다.
3. 사진 정보 아래에 포인터 위치, RGB 값, HEX 값과 색상 견본을 표시합니다. 회전·반전·밝기 등을 반영한 표시 이미지의 픽셀을 기준으로 하며, 사진 바깥으로 이동하거나 사진을 바꾸면 안내를 초기화합니다.
4. 파일목록 제목 옆에서 파일명만 / 작은 아이콘 + 파일명 / 아이콘 격자를 선택합니다. 기존 보기 메뉴와 연동합니다.
5. 상단 아이콘에 색상별 기능 구분, 둥근 모서리, 그라데이션, 밝은 가장자리와 그림자를 적용했습니다. 마우스를 올리면 기존 기능 설명이 표시됩니다.
6. 뷰어·편집을 좌우로 선택하는 스위치로 변경했습니다. 선택 위치의 슬라이더와 작은 LED가 켜집니다. 클릭·드래그 및 포커스를 둔 상태에서 방향키·스페이스로 선택할 수 있습니다.
7. 스위치와 아이콘에 부드러운 곡선과 입체감을 적용했습니다. 기본 까마귀 브랜드는 유지합니다.

## 오른쪽 기능 사용

- **정보**: 사진 정보와 포인터 색상 표시. 상단 정보 아이콘 또는 F8도 이 페이지를 엽니다.
- **AI 생성 판단**: ‘현재 사진 출처 검사’를 눌러 C2PA 생성·편집 기록을 확인합니다. AI 생성/편집 선언, 검증 상태 및 검사한 파일명을 표시합니다. 출처 기록이 없으면 판별 불가입니다. 픽셀로 AI 여부를 추측하는 새 모델은 추가하지 않았습니다.
- **성인 필터**: 끄기/켜기를 선택한 뒤 ‘필터 적용’을 누릅니다. 켤 때 기존 로컬 모델을 불러옵니다. 켜짐 상태에서는 판별 불가 파일도 숨깁니다.
- **도구**: 전체 이미지 OCR, 영역 OCR, 촬영일 색인, OCR 내용 색인, 촬영일·글자 검색. OCR·색인의 진행과 결과가 같은 오른쪽 열에 표시됩니다. 작은 창에서는 이 열을 스크롤할 수 있습니다.

탭 선택만으로 C2PA/성인 필터/RAW 모델을 불러오지 않습니다. 사진 보기의 기존 지연 로딩 구조를 유지합니다. 저장·내보내기 등 다른 명시적 작업은 기존 내부 보조 패널을 사용합니다.

- `tools/check_workspace.py`: 모드 전환 시 상태 유지, 메뉴, 전체 화면, 작은 창, OCR 결과 및 촬영일 색인 PASS.
