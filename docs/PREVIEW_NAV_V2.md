버전은 2.0.0을 유지합니다. 옆의 _internal 폴더가 필요합니다. 설치 프로그램·ZIP·MSIX 및 GitHub/Store 업로드는 수행하지 않았습니다.

## 요청한 8가지 반영

1. 좌상단 CrowEyes는 기존 지정 크기 21에서 23으로 올리고 Segoe UI Bold를 적용했습니다. 실제 브랜드 위젯에도 이 스타일이 적용되도록 보정했습니다.
2. 두 번째 줄에 폴더 경로 / 파일 찾기 / 정보 / AI 생성 판단 / 성인 필터 / 도구를 한 줄로 배치했습니다. 경로는 긴 폴더명도 나머지 버튼을 밀어내지 않는 입력 칸으로 표시합니다. 폴더 아이콘을 누르면 폴더를 열 수 있고, 경로의 전체 내용은 마우스를 올려 확인할 수 있습니다. 오른쪽 페이지 인덱스는 제거했습니다.
3. 환경설정은 2열 항목 배치와 내용에 맞는 크기를 사용합니다. 스크롤바가 없습니다. 테마 선택은 파랑, 휠 동작 선택은 초록으로 구분하며 선택 목록의 색상과 글자 크기도 맞췄습니다. 재생 간격이 잘못된 경우 창 안에서 안내합니다.
4. 보기·성능 창도 내용에 맞는 높이와 폭으로 변경하고 스크롤바를 없앴습니다.
5. 기본 포함 기능 안내는 빠른 보기·출처 / 필터·글자 인식 / 편집·단축키의 3개 탭으로 구성했습니다. 각 기능의 사용 위치, 동작, 특징, 실제 제공하는 단축키를 설명합니다. C2PA 기록이 없으면 판단할 수 없다는 점과 모델이 필요할 때만 로드된다는 점을 안내합니다.
6. 첫 실행 목록은 4열 아이콘 격자입니다. 이전 UI 설정도 이번 검토본 최초 실행 때 한 번 격자로 전환합니다. 이후 사용자가 고른 파일명·작은 아이콘·격자 보기 방식은 계속 저장합니다. 목록의 초기 폭도 4열 썸네일에 맞췄습니다.
7. 뷰어·편집 전환 시 오른쪽 세 번째 열은 닫습니다. 상단 정보 / AI 생성 판단 / 성인 필터 / 도구 버튼으로 필요할 때 엽니다. 같은 버튼을 다시 누르면 닫습니다. 전체 화면에서는 탐색 줄 전체가 숨겨집니다.
8. 사진 정보 안의 C2PA 출처·AI 선언·출처 검증 항목과 하단 픽셀 색상 견본을 제거했습니다. 출처 검사는 AI 생성 판단 페이지에서 확인하고, 포인터 위치·색상은 기존 좌하단 상태 표시를 사용합니다.
