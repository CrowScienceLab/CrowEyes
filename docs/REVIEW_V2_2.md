# CrowEyes 2.2 검토본

작성일: 2026-11-11. 앱/GitHub 버전 2.2.0, Store 버전 2.2.0.0.
GitHub 업로드, Store 제출 및 기존 앱 설치 변경은 진행하지 않았습니다.

## 변경 내용

- 업데이트 확인은 GitHub와 Microsoft Store를 함께 확인합니다. 같은 최신 버전은 Store를 우선하며, 서로 다른 버전은 더 최신 버전을 선택합니다. Store 설치형은 외부 설치 파일로 교체하지 않고 Store를 안내합니다. 한쪽 조회에 실패하면 최신이라고 단정하지 않습니다.
- 좌상단 CrowEyes 글자를 Normal로 변경했습니다. 편집 화면에도 인쇄 아이콘을 추가했습니다.
- 인쇄 창을 크기 조절 가능한 창으로 교체했습니다. 앱 중앙에서 열리며, 하단 인쇄/닫기는 설정 영역과 분리했습니다.
- 인쇄 설정은 기본 / 크기·여백 / 분할 출력 탭으로 나눴습니다. 배율 1~1000%, 상하좌우 여백(mm), DPI, 용지 방향, 부수를 지정할 수 있습니다. 원본 DPI 정보가 있으면 이를 반영하며, 축소 미리보기 소스의 물리 크기도 보정합니다.
- 한 이미지를 2장 또는 4장에 나눠 출력합니다. 2장은 이미지 비율에 따라 배치를 선택하고, 4장은 2×2로 배치합니다. 미리보기에는 페이지 번호와 점선 분할 경계를 표시합니다. 점선 자체는 인쇄하지 않습니다.
- 프린터의 인쇄 불가능 영역을 여백에 반영합니다. 원본/사용자 배율에서 이미지가 용지를 넘으면 경고하고, 잘리는 출력을 진행하기 전에 확인합니다.
- Store 설치 후 첫 실행에 바탕화면 바로가기 추가 여부를 선택하는 안내를 표시합니다. 바로가기는 버전이 바뀌어도 사용할 수 있는 앱 식별자로 실행합니다. 기존 바로가기는 덮어쓰지 않습니다.
- Store의 이미지 형식 등록과 기본 앱 지정 방법을 안내합니다. 기존 Windows 기본 앱 선택은 유지하며 Windows 기본 앱 설정을 여는 버튼을 제공합니다.

## 검토 방법

1. `release/review-v2.2.0`의 Portable ZIP을 새 폴더에 풀고 CrowEyes.exe를 실행합니다. 설치하지 않고 검토할 때 권장합니다.
2. 뷰어와 편집 각각에서 인쇄 아이콘을 확인합니다.
3. 인쇄 창에서 배율 50/100/150%, 네 방향 여백, 세로/가로 용지를 바꾸며 실제 인쇄 크기(mm)를 확인합니다.
4. 분할 출력에서 2장/4장을 선택하고 미리보기의 페이지와 점선을 확인합니다. `Microsoft Print to PDF`와 파일로 출력을 선택하면 실제 종이를 쓰지 않고 확인할 수 있습니다.
5. A2를 A4 4장으로 출력할 때는 원본 크기 또는 배율을 선택하세요. 프린터 여백이 있으면 A2 전체 크기를 담기에 부족할 수 있습니다. 이때 경고를 확인하고, 전체 용지에 맞춤을 선택하거나 무테 지원 프린터를 사용하세요. 여백을 잘라 이어 붙이는 방식이며 겹침/재단 마크 옵션은 제공하지 않습니다.

## 검증 및 제한

- 소스 회귀 검사: OCR, 2.1 정렬/숨김, 파일 선택, 경로, 화면 전환, 편집, 업데이트 호환성, UI 경계 등 통과. 새 인쇄 배율/여백/분할 계산과 Store/GitHub 우선순위 및 실패 처리를 검사했습니다.
- 실행 파일 검사: 포함 C2PA/성인 필터/RAW 런타임, OCR, Store API 바인딩, 화면 전환 및 편집 회귀 검사 통과. 시작 시 무거운 모델이 로드되지 않음을 확인했습니다.
- 실제 Windows 인쇄 함수로 Microsoft Print to PDF에 출력하고 Poppler로 렌더링해 2장/4장 페이지 수, 이미지 순서와 여백을 확인했습니다. 상세 결과는 `docs/maintenance/2026-11-11-v2.2-review`에 보존합니다.
- Store 서비스의 실제 업데이트 반환과 Store 설치 환경의 바로가기 실행은 서명된 Store 패키지 설치 후 최종 확인이 필요합니다. 이 검토 단계에서는 시스템 기본 앱이나 사용자 바탕화면을 변경하지 않았습니다.
- MSIX는 설치 중 사용자 정의 질문을 띄우지 않으므로, 바로가기 질문은 설치 후 첫 실행에 표시합니다. Windows는 앱이 사용자의 기본 연결을 강제로 변경하는 것을 허용하지 않습니다. 패키지가 연결 프로그램 후보를 등록하고 사용자가 기본 앱을 선택하도록 안내하는 방식입니다.
- 검토용 EXE/설치 파일은 서명하지 않았습니다. MSIX는 패키징 검증용이며 Store 인증 완료를 의미하지 않습니다.

## 다음 게시 시 주의

`update-channels.json`은 Store에서 실제 공개된 버전만 기록합니다. 현재 2.1.0을 유지합니다. 2.2 Store 게시가 확인되기 전에 올리지 마세요. 일반 설치형은 공개 Store 상품 페이지 접속과 이 게시 확인 정보를 함께 사용하고, Store 설치형은 StoreContext 공식 업데이트 API도 조회합니다. 일반 설치형에서 Store의 정확한 버전을 조회할 수 있는 공개 API를 가정하지 않습니다.

변경 모듈: `croweyes_updates.py`, `croweyes_onboarding.py`, `croweyes_printing.py`, `croweyes_print_ui.py`. 버전 원본은 `version.json`입니다. 기존 소스 파일명과 클래스명은 호환성을 위해 유지했습니다.
