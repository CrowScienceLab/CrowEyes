## 요청 반영
1. 좌상단 CrowEyes: Segoe UI 22 Bold (기존 23에서 -1).
2. 경로를 컴퓨터 아이콘 > 클릭 가능한 폴더명으로 표시. 셀 배경·테두리 제거, 마우스 위에서만 밑줄. 컴퓨터 아이콘은 긴 경로에서도 고정. 긴 경로는 휠과 우측 … 메뉴로 상위 폴더 접근.
3. AI 생성 판단 버튼은 곧바로 현재 이미지의 C2PA 검사 시작, 중앙 내부 창으로 결과 표시. 제3열을 열지 않음.
4. 성인 필터 아이콘을 빨간 원형 19 배지로 변경. 설명 / ON·OFF / 적용을 작은 내부 창에 표시.
5. 영역 OCR은 사각형과 연필 Windows 커서, 검정 외곽선 + 노란 선택선 적용. 인식 결과는 내부 창에서 복사 가능.
6. 정보 색인 결과는 내용 크기에 맞는 내부 창. 스크롤바 및 전체 복사 삭제. 긴 결과는 이전·다음으로 전부 열람 가능.
7. 선택한 썸네일은 3px 선명한 파란 테두리. 선택 여부에 따라 셀 크기가 달라지지 않음.
8. 목록의 빈 여백에서 드래그하여 사각형 다중 선택. Ctrl을 누르면 기존 선택에 추가. 가장자리에서 자동 스크롤. 썸네일에서 시작하는 기존 파일 끌어놓기는 유지.
9. 뷰어 상단: 슬라이드쇼 → 인쇄 → 선택 이미지 비교. 인쇄 Ctrl+P 및 기존 파일 메뉴 유지.
