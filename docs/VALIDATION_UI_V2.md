# CrowEyes 2.0 UI 개편 검토 · 2026-10-11

소스와 로컬 배포 패키지를 준비했습니다. GitHub 또는 Microsoft Store 업로드는 수행하지 않았습니다. 공통 버전은 제품·PE·Setup·Portable 2.0.0, GitHub v2.0.0, Store 2.0.0.0입니다.

## 화면 구성

- 뷰어: 기존 파일 목록 / 중앙 사진 / 사진 정보 구조. 상단에 열기·폴더·이동·맞춤·100%·확대·축소·재생·비교·정보를 배치합니다.
- 편집: 중앙 사진 / 오른쪽 편집 패널 / 하단 필름스트립. 상단에 이동·실행 취소·재실행·전후 비교·사본 저장을 배치합니다. 사진과 편집 값, 수동 확대 상태를 유지하며 전환합니다.
- 파일·보기·편집·정리·도구·설정으로 기존 기능을 분산했습니다. 더보기의 버전별 작업 도구 묶음을 제거하고 우클릭도 같은 작업 분류를 사용합니다.
- 32px 아이콘과 한글 기능명을 함께 표시하며 창이 좁아지면 도구를 줄바꿈합니다. 편집 패널은 작은 창에서 스크롤할 수 있습니다.
- 노란부리 까마귀 로고는 CrowShow의 검은 깃털·노란 부리·푸른 가장자리 스타일을 참고하여 사진 배지로 구분했습니다. PNG/다중 크기 ICO를 앱·설치 파일·Store 로고에 공통 적용했습니다.
- 편집 필름스트립은 창 폭에 따라 최대 11개를 백그라운드로 읽습니다. 뷰어 모드에서는 생성하지 않고, 모드 전환만으로 AI 모델이나 색인을 실행하지 않습니다.

## 검증 결과

소스 UI 검사: 반복 모드 전환, 편집·확대 상태 유지, 패널 구성, 필름스트립, 전체 화면, 테마 변경, 800×600 줄바꿈 및 필름스트립 가로 범위, 선택 AI 라이브러리 미로드 PASS.

회귀 검사: 테마 대비, 목록 다중 선택·폴더 이동, F5 슬라이드쇼와 도구 모음 크기, PSD/SVG·인쇄·raster 처리 PASS. 실제 파일의 내보내기·충돌 처리·취소·EXIF/ICC·분류·중복·주석·편집 이력과 작업 창 생성 PASS.

최종 배포 EXE 자동 UI 검사: 뷰어/편집, 상태 유지, 필름스트립, 6개 메뉴, 800×600 범위, 무거운 모듈 미로드 PASS. Tk callback 오류 없음. 프로그램 PE 버전 2.0.0 확인.

최종 배포 EXE 기능 검사: 네 종류 선택 모듈 ZIP 설치, C2PA 기록 없음 처리, 필터 실제 추론, RAW 미리보기, CLIP 실제 추론 PASS. HEIC 120×80와 CR2 미리보기 1936×1288 확인. 서명된 C2PA 샘플 검사 종료 코드 0. 이번 OCR 검사는 빈 단색 이미지로 런타임 호출만 확인했으며 문자열 인식 근거는 기존 기능 검토 보고서에 있습니다.

Setup 생성, Portable ZIP 및 모듈 ZIP CRC, MSIX 패키징·manifest 버전, 7개 파일 SHA-256 및 기존 선택 모듈 해시 일치 PASS. 기본 번들에 C2PA/NumPy/ONNX/rawpy/tokenizers/pillow_heif 패키지를 포함하지 않습니다.
