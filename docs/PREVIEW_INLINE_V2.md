`D:\App coding\Crow Eyes\dist\preview-v2.0.0\CrowEyes\CrowEyes.exe`

폴더에서 CrowEyes.exe를 실행하세요. 옆의 _internal 폴더가 필요하므로 실행 파일만 다른 위치로 옮기면 안 됩니다. 제품 버전은 2.0.0을 유지합니다.

## 이번 네 가지 수정

1. 가로·세로 사진 모두 썸네일의 둥근 정사각형을 채웁니다. 원본 비율을 유지하며 중앙을 기준으로 필요한 가장자리를 잘라 표시합니다. 원본 파일은 바꾸지 않습니다. 이전 여백형 썸네일과 캐시 키를 분리했습니다.
2. 편집 화면의 오른쪽 편집 패널을 제거하고 해당 기능을 상단 아이콘으로 옮겼습니다. 편집 전환 직후 아이콘이 시스템 기본 회색 스타일로 표시되던 문제는 제품 테마를 재적용하여 수정했습니다. 회전·반전·취소·재실행은 즉시 실행하며, 밝기·대비와 크기·비율 설정은 사진 위의 인라인 조절 줄을 사용합니다.
3. 하단 필름스트립을 제거하고 뷰어의 왼쪽 파일목록을 편집에서도 사용합니다. 스크롤·선택·폴더 탐색은 동일한 기존 목록 위젯을 사용합니다.
4. 주석 / 형광펜 / 모자이크를 독립 아이콘과 메뉴 항목으로 분리했습니다. 사진 위에서 직접 드래그하여 적용하고 별도 작은 편집창을 띄우지 않습니다. 주석의 텍스트·화살표·사각형은 인라인 선택으로 설정합니다. 저장 품질·내보내기와 전후 비교 같은 명시적 작업은 기존 앱 내부 보조 패널을 사용합니다.

## 편집 확인 순서

- 사진을 연 뒤 편집을 선택합니다. 왼쪽 파일목록이 유지되고 오른쪽 편집 패널·하단 필름스트립이 없는지 확인합니다.
- 주석 아이콘은 텍스트·화살표·사각형을 선택할 수 있습니다. 텍스트는 조절 줄에 입력하고 사진 위에 표시합니다.
- 형광펜과 모자이크는 각각 아이콘을 선택한 뒤 사진 위에서 영역을 드래그합니다.
- 실행 취소·재실행·원본 복원, 회전·반전 후 주석 위치, 사본 저장을 확인합니다. 완료를 누르면 드래그 편집 도구를 종료합니다.
- 크기·비율 아이콘에서 가로·세로를 입력하고 저장합니다. 비율 유지 상태에서는 지정 상자에 맞춰 확대/축소하며, 해제하면 입력한 가로·세로로 저장합니다.
