## 구현 범위

영역 저장·클립보드와 비율 변경 저장을 유지했습니다. 일괄 변환·크기·이름 변경, 별도 일괄 이름 변경, 실행 취소·재실행·원본 복원·전후 비교, 주석 5종, 2/4장 동기 비교, 저장 품질 미리보기·목표 용량·프리셋을 추가했습니다. EXIF/GPS/촬영일, 개인정보 기본 제거·EXIF 보존 선택, ICC 변환, 별점·태그·즐겨찾기·날짜/내용 검색, 정확/유사 중복 검색, 전체/영역 OCR과 OCR 색인을 제공합니다.

AVIF는 기본 지원, HEIC/HEIF는 Windows 설치 코덱, RAW는 선택 모듈의 내장 미리보기입니다. 로컬 CLIP 내용 검색도 별도 선택 모듈입니다. C2PA는 자동 점수 표시를 제거하고 명시적 검사·지연 로딩·결과 캐시·구조화된 출처 선언 및 검증 상태를 적용했습니다. 기록 없음은 AI 여부를 판별할 수 없다는 뜻입니다.

커서 기준 확대, 다음 사진 확대 유지, 128MiB 디코딩 캐시 예산, 약 100MiB 지속 썸네일 캐시, 고해상도 축소 미리보기를 적용했습니다. 기능별 소스를 분리했고 C2PA/NumPy/ONNX/tokenizers/RAW 및 모델은 기본 번들에서 제외했습니다.

## 용량과 속도

같은 onedir 방식 기본 배포 크기는 1.9e 190,445,794 bytes(181.62MiB)에서 2.0 54,023,520 bytes(51.52MiB)로 약 71.6% 감소했습니다. Setup 17.86MiB, Portable 23.47MiB, MSIX 24.95MiB입니다. 선택 ZIP은 C2PA 8.04MiB, 필터 35.10MiB, RAW 12.53MiB, 내용 검색 135.27MiB입니다. 선택 모듈 설치 시 압축 해제 공간도 필요하며 전체를 설치하면 총 설치 크기는 증가합니다.

400×200 동일 이미지로 버전별 3회, 새 Python 프로세스를 교차 실행한 중앙값: 첫 이미지 1.9e 545ms / 2.0 393ms, 확대 redraw 4.69ms / 0.85ms, working set 57.59MiB / 54.39MiB. OS 캐시는 비우지 않았으며 소스 실행 측정입니다. 배포 EXE의 cold start, 대규모 실제 폴더와 다양한 PC에서 같은 수치를 보장하지 않습니다. 기본 시작에서 무거운 라이브러리가 로드되지 않는 것은 배포 EXE에서도 별도로 확인했습니다.

## 검토 시 유의할 범위

고해상도 현재 보기에서 저장은 표시 미리보기 픽셀 기준이며 일괄 변환은 원본을 읽습니다. RAW는 현상이 아닌 내장 미리보기입니다. HEIC/RAW EXIF/GPS 추출은 지원하지 않는다고 표시합니다. HEIC는 PC의 Windows 코덱이 필요합니다. 의미 검색은 영어 설명 기반이며 한국어 글자 검색은 OCR을 사용합니다. OCR은 Windows 설치 언어에 따릅니다. 선택 모델/대량 색인은 실행 중 CPU·메모리를 사용합니다.

보안 필터를 켜면 비교·일괄 처리·OCR 색인·내용 검색에도 작업 제한을 적용합니다. 모듈 ZIP은 버전별 SHA-256을 고정하며 교체하면 코어도 재빌드해야 합니다. 유사 중복 결과는 자동 삭제하지 않습니다. 내보내기는 기존 C2PA 서명을 복제하지 않으며 저장 시 EXIF 보존을 선택하지 않으면 개인정보를 제거합니다.

이 PC에서의 검증 결과이며 Store 인증, 별도 Windows 10/11 장치의 전체 설치·업그레이드·제거 검증까지 완료한 것은 아닙니다. 실행 파일은 기존과 같이 무서명입니다. 사용자 검토 뒤 업로드를 진행합니다.
