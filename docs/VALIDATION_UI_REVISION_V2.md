# CrowEyes 2.0 UI 재검토 · 2026-10-11

요청된 12개 수정 항목을 적용하고 로컬 검토 패키지를 다시 생성했습니다. GitHub/Store에는 업로드하지 않았습니다. 공통 버전 2.0.0 / v2.0.0 / Store 2.0.0.0을 유지합니다. 이전 UI 검토본과 AI 검색 소스는 복구할 수 있도록 _archive에 보존합니다.

## 반영한 항목

1. 상단 버튼 셀 방식 메뉴를 Windows/Tk 시스템 기본 메뉴로 바꿨습니다. 앱의 테마 색을 메뉴 항목에 강제 지정하지 않습니다.
2. 뷰어/편집 상단 도구 목록을 동일하게 유지합니다. 편집 기능은 오른쪽 편집 패널과 편집 메뉴에서 실행합니다. 경로·검색 줄도 두 작업 공간에서 유지합니다.
3. CrowEyes·뷰어·편집 뒤에 열기 / 폴더 / 이전 / 다음 / 화면맞춤 / 축소 / 100% / 확대 / 재생 / 비교 / 정보를 배치했습니다. 32px 아이콘만 표시하며 마우스를 올리면 이름이 나타납니다. 좁은 창에서는 줄바꿈합니다.
4. 파일 목록 위 새로고침·내 컴퓨터 버튼을 제거했습니다. 드라이브 탐색과 폴더 열기 기능은 유지합니다.
5. 파일 목록 썸네일은 동일한 둥근 정사각형 안에 원본 비율을 유지하여 중앙 배치합니다. 기존 디스크 썸네일 캐시와 구분하는 새 캐시 키를 사용합니다.
6. 편집 필름스트립에도 같은 썸네일 함수를 사용합니다.
7. 정보 패널은 기존 저장 설정과 관계없이 시작할 때 숨깁니다.
8. 창 오른쪽에 작은 정보 탭을 표시합니다. 탭 또는 상단 정보 아이콘으로 패널을 열고 닫습니다. 편집에서도 정보 패널을 열 수 있습니다.
9. 별점·태그·즐겨찾기 메뉴, 편집 창 및 검색 조건을 제거했습니다. 기존 DB에 저장된 사용자 데이터는 삭제하지 않습니다. 촬영일·OCR 색인은 유지합니다.
10. AI 내용 검색의 메뉴와 실행 코드를 제거했습니다. CLIP 모델과 tokenizers를 배포하지 않습니다.
11. C2PA·성인 콘텐츠 필터·RAW 미리보기를 기본 포함합니다. 세 런타임의 동일한 NumPy·ONNX 파일을 공유합니다. 출처 검사 / 필터 켜기 / RAW 열기 때만 로드하며 별도 설치가 필요하지 않습니다. 콘텐츠 필터는 기본 꺼짐입니다.
12. OCR 결과, 색인 진행·결과, 검색, 편집 작업과 환경설정을 앱 내부 중앙 보조 패널에 표시합니다. 진행창 460×220, 글자 결과창 560×340을 기준으로 앱 크기에 맞춰 제한하고, 긴 내용은 내부 스크롤로 확인합니다. 파일 선택·Windows 시스템 안내 등 OS 대화상자는 별도로 사용합니다.

- 썸네일: 72×72 동일 크기, 투명한 둥근 모서리, 중앙 불투명 사진 영역 확인 PASS.

- 회귀: 테마 텍스트 대비, 목록 다중 선택·폴더 탐색, F5 슬라이드쇼·툴팁/도구 범위, PSD/SVG·인쇄·raster 처리 PASS.

- Setup 생성, Portable ZIP CRC, MSIX 생성 및 manifest 2.0.0.0, PE 2.0.0, 기본 포함 런타임 파일별 SHA-256 일치, 3개 배포 파일의 해시 생성 PASS.
